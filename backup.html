Aplicação para alojamento web

A aplicação completa num ZIP, com o mesmo login. Escolha a versão conforme o alojamento.

  1. Descarregue e extraia o ZIP.
  2. Envie os ficheiros por FTP ou pelo Gestor de Ficheiros para public_html (ou uma subpasta).
  3. Abra o endereço do site e entre com o utilizador e a senha habituais.

Com PHP (cPanel, Plesk…): base de dados própria no alojamento, já com os clientes atuais. Requer PHP 7.4+ com SQLite.
GitHub Pages / sem PHP: só ficheiros estáticos; os clientes ficam na base de dados na nuvem, os mesmos deste painel.
